# Buddhadeb Chhetri — Personal Portfolio

A sleek, modern, and SEO-optimized personal portfolio and digital playground built to showcase my games, web projects, and interactive experiences. 

🌍 **Live Website:** [buddhadebchhetri.in](https://buddhadebchhetri.in)

## 🚀 Features
- **Custom SPA Routing**: Fast, lightweight path-based routing using the HTML5 History API.
- **Dynamic SEO**: Fully optimized with `react-helmet-async` for per-page meta tags, Open Graph cards, and Twitter summaries. Contains a static Sitemap and Robots.txt.
- **Dark/Light Mode**: First-class theme support built into the UI.
- **Fully Responsive**: Carefully crafted with Tailwind CSS to look great on desktops, tablets, and mobile devices.
- **Type-Safe**: Written in TypeScript for robust and maintainable code.

## 🛠️ Tech Stack
- **Framework**: [React 18](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Configured for Vercel

## 💻 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) and [pnpm](https://pnpm.io/) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/buddhad/myportfolio.git
   ```
2. Navigate into the project directory:
   ```bash
   cd myportfolio
   ```
3. Install the dependencies using `pnpm`:
   ```bash
   pnpm install
   ```

### Running Locally

Start the Vite development server:
```bash
pnpm dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### Building for Production

To create a production-ready build:
```bash
pnpm build
```
You can then preview the build locally using:
```bash
pnpm preview
```
